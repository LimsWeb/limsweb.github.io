# 초임계 추출 예측

**공정 최적화라는 현장 목적을 데이터 정제와 추출 결과 예측 모델로 구체화했습니다.**

- 상태: 데이터 정제·모델 학습 수행
- 역할: 데이터 정제 · ML 모델 학습·평가
- 활용: Python, 데이터 정제, 머신러닝, 회귀 예측

## 현장의 질문을 예측 문제로

바이오진흥원 관련 프로젝트에서 초임계 추출 장비의 공정 최적화를 목적으로 추출 결과 예측 모델을 구현했습니다. 현장 목적을 학습 가능한 데이터 문제로 바꾸는 경험이었습니다.

## 내가 수행한 범위

학습용 데이터를 정제하고 분석·학습에 필요한 형태로 처리했습니다. 머신러닝 모델을 학습·평가하고, 예측 결과를 공정 최적화 목적에 어떻게 활용할지 검토했습니다.

## 결정계수 R² = 0.83

당시 회귀 모델 평가에서 결정계수 R² = 0.83을 기록했습니다. 데이터 규모, 학습·검증 분할과 모델별 상세 조건은 추가 자료로 보완할 항목입니다.

이 값은 회귀 평가 지표입니다. 수율 향상이나 원가 절감 등 실제 공정 개선 효과는 별도 검증이 필요합니다.
