회의록 summary

회의 음성의 입력부터 처리 상태 확인과 기록 조회까지, 회의 정리 흐름을 구현했습니다.

개인용 프로토타입 · 개선 중

회의 파일을 다시 찾는 기록으로

회의 음성의 전사·요약을 회의록으로 정리하고 이전 기록을 다시 확인하는 개인용 도구를 개발했습니다. 오성순의 대화 요약과는 별도 프로젝트입니다.

입력·처리·기록의 사용 흐름

음성 파일 선택, 회의 제목 입력과 생성 요청 화면을 구성하고 처리 진행 표시·로그·이전 기록 조회 흐름을 구현했습니다. 업무 목적과 요구사항을 정하고 AI 코딩 도구와 협업해 개발했습니다.

현재 확인한 지점

실제 음성 파일 처리에서 요약 단계의 HTTP 500 오류를 확인했습니다. 문제 상황을 질문하고 수정 방향을 검토했으며, 최종 회의록 생성·저장까지 이어지는 동작은 개선 과제로 남아 있습니다.

다음 검증

입력부터 최종 저장까지 성공한 사례와 실패 조건을 남기고, 원음·전사·요약을 비교해 품질을 확인하려 합니다. 현재는 사용 흐름을 구현하고 처리 문제를 점검하는 프로토타입 단계입니다.
