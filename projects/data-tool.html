데이터관리 Tool

파일 업로드에서 데이터 파악, 분석 결과 확인과 질문까지 이어지는 업무 도구를 기획했습니다.

기획·개발 진행 리드 경험

파일을 받은 다음의 업무까지

데이터 파일을 입력받은 뒤 상태와 특성을 파악하고, 분석 결과를 확인하고 질문하는 흐름을 하나의 도구로 정리했습니다.

기능의 순서와 범위를 정하기

도구의 목적과 기능 방향을 정하고 요구사항·우선순위를 구체화하며 개발 진행을 리드했습니다. 기술 기능이 실제 데이터 확인 업무에서 어떻게 이어지는지에 초점을 두었습니다.

CSV·XLSX 입력, 프로파일링과 요약, 분석 결과 확인, LLM 질의응답을 연결하는 구성을 다뤘습니다. Gradio 기반 화면과 데이터 프로파일링 도구의 활용 방향도 정리했습니다.
