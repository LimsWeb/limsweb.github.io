오성순

대화와 작업의 맥락을 이어가기 위해 직접 사용하며 다듬는 개인용 로컬 AI 비서입니다.

개인 사용·개발·개선 중

내 업무의 맥락을 이어가는 비서

대화와 자료, 진행 중인 작업을 이어가고 로컬 AI와 개발 도구를 한 작업 환경에서 쓰기 위해 시작했습니다. Telegram 기반 대화에서 웹 대시보드로 사용 환경을 넓히고 있습니다.

기능보다 먼저 정한 사용 방식

개인 업무에 필요한 대화·기억·상태 관리 요구사항과 인터페이스, 개발 우선순위를 정했습니다. AI가 제시한 코드와 오류 설명을 확인하고 질문하며 수정 방향을 조율했습니다.

Python·Ollama 기반 로컬 모델 호출, Telegram 대화와 기록·상태 관리 기능을 구현하고 사용했습니다. 긴 로그와 진행 상태를 확인하는 불편을 웹 대시보드 개선으로 연결했습니다.

실제로 써보며 만난 제약

응답 지연과 호출·연결 오류를 경험하며 16GB GPU와 원격 접속 조건에 맞춰 기능 범위를 조정하고 있습니다. Codex·OpenCode 등 개발 도구와의 연결도 검토·실험하고 있습니다.

개인 업무에서 답변이 쓸 만한지, 얼마나 기다려야 하는지, 도구 연결이 동작하는지를 중심으로 개선 중입니다.

다음에 남길 기록

자주 쓰는 업무별 성공 조건, 실패 이유와 변경 후 동작을 기록하려 합니다. 현재는 개인용 로컬 도구이며, 다른 구성원이 함께 쓰는 서비스로의 확장은 별도 구상입니다.
